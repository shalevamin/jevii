# macOS

jevii is Mac-first.

## Required permissions

- **Accessibility** — UI control / AX helpers
- **Screen Recording** — vision screenshots for mouse/keyboard control

Optional: Full Disk Access for some file workflows.

```bash
jevii open-settings --all
```

## Paths

| Path | Purpose |
| --- | --- |
| `~/jevii` | Default root after install |
| `~/jevii/.env` | Local secrets (never commit) |
| `~/jevii/.auth/` | OAuth stores |
| `~/.jev-ultrafast-mcp/TYPESAFE_API_KEY` | TypeSafe key file |
