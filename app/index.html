Telegram

Create a bot with @BotFather, paste the token, then Start bridge. jevii replies in Telegram with your connected model.

  1. Open Telegram → search @BotFather.
  2. Send /newbot, pick a name and username ending in bot.
  3. Copy the token BotFather sends (looks like 123456:ABC…).
  4. Paste it below → Save token (stored in ~/jevii/.env, chmod 600).
  5. Optional: paste allowed numeric chat id(s), comma-separated (ask @userinfobot).
  6. Click Start bridge, then message your bot with /start.
